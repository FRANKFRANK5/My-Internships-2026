 # 💰 overtime pay calculator

### 📌 Demonstration
This is the professional **python-based** utility designed to automate employmee wage calculation. This system efficiently handles overtime ;ogic, applying a **1.5x multiplier** for all hours worked beyond the standard 40-hours limit. 🚀

### 🛠️ How to use:
1. Ensure **python** 🐍 is installed on your local machine.
2. Run the 'auto_repay.pay' file
3. Enter the total number of hours worked when prompted. ⌨️
4. Enter your hourly pay rate. 💸
5. The system will automatically compute and display the **Gross Pay**. ✅

### ✨ key Features:
* 🛡️ **Overtime Logic** Intelligent detection of hours exceeding 40.
* 📊 **Currency Formatting:** Outputs results with the `$` symbol and commas.
* 🏆 **Professional Banner:** Features a custom "CHAMPION 2026" header. 🔥
